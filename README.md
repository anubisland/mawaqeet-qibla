# مواقيت الصلاة والقبلة | Mawaqeet & Qibla (AnubisLand)

تطبيق ويب تقدمي (**PWA**) احترافي لتحديد **مواقيت الصلاة** بدقة فلكية عالية في أي مكان في العالم، وتحديد **اتجاه القبلة** بالبوصلة التفاعلية الذكية، من تطوير شركة **AnubisLand**.

🌐 **الرابط المباشر:** https://anubisland.github.io/mawaqeet-qibla/

## المميزات الرئيسية
- **حساب فلكي دقيق دون الحاجة للإنترنت:** يدعم 10 هيئات حساب عالمية (الهيئة المصرية، أم القرى، رابطة العالم الإسلامي، ISNA، كراتشي، دبي، الكويت، قطر، سنغافورة، ديانت تركيا) مع دعم المذهب الحنفي والجمهور وتعديل خطوط العرض العليا.
- **تحديد الموقع عالمياً:** قاعدة بيانات مدمجة لأشهر مدن العالم + تحديد الموقع عبر GPS + بحث عالمي (OpenStreetMap) + إدخال إحداثيات مخصصة + حفظ المدن المفضلة.
- **بطاقات ملونة جذابة:** تصميم أنيق ببطاقات ملونة لكل صلاة مع عداد تنازلي حي للصلاة القادمة ومواقيت منتصف الليل والثلث الأخير.
- **بوصلة القبلة التفاعلية والذكية:** تدعم مستشعر الهاتف، محاكي اتجاه للحاسوب، خريطة المسار الدائري الأعظم إلى الكعبة المشرفة، وتحديد القبلة بالشمس.
- **الجدول الشهري والتصدير:** عرض الشهر كاملاً مع الطباعة/PDF وتصدير ملف تقويم `.ics`.
- **متابعة الصلوات والسنن + التنبيهات:** قائمة متابعة يومية للفروض والسنن الرواتب + إشعارات المتصفح ونغمة تنبيه لطيفة.
- **ثنائي اللغة (عربي / إنجليزي) + الوضع الفاتح والداكن + التحكم في الخط وحجمه + قابل للتثبيت كـ PWA.**
